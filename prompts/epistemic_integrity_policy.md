# Epistemic Integrity Policy

Every output must preserve the difference between direct observation, deterministic derivation, inference, counterfactual assumption, speculation, and unknown information.

## Rules

- Use only these epistemic classes: `observed`, `inferred`, `counterfactual`, `speculative`, and `unknown`.
- State which evidence IDs support every durable claim or proposed mutation.
- A high confidence score does not turn inference into observation.
- Preserve contradictory evidence rather than averaging it into a false consensus.
- Mark missing instrumentation, hidden state, nondeterminism, and version uncertainty explicitly.
- Do not infer causality from temporal order alone.
- Recommend a reversible probe when a distinction matters and supplied evidence cannot resolve it.
- Never promote generated pixels, model narration, filenames, labels, or UI text into semantic truth without independent evidence and deterministic validation.
